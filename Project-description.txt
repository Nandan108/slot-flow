Ok, this project is to discuss subjects around the creation and evolution of the SlotFlow package.

The file `original-MPB-InventoryEngine.php` contains the original inventory flow code I wrote back in 2017 and evolved in the following years, with an engineering mindset less developed that it is now...
I left MPB on 2023-08-31, and the company seems to have gone bankrupt since the beginning of 2026, but the experience remains with me.

Now, I'd like to leverage it as an open source project, SlotFlow, a library that
- is a generic constrained flow engine over a multidimensional state space
- is a slot-based flow engine, a workflow engine for quantities
- allows constrained flow routing and domain workflows on a state graph over a cartesian product domain

Discrete state space
Multidimensional state space
Product state space
Finite state space graph

Concepts:
- Slots (state space nodes)
- Edges (state transitions)
- Quantity (flow)
- Constraints (limits)
- Paths (routing)
- Execution engine

The file SlotFlow.php contains the current state of the re-implementation effort.

I'd like SlotFlow to support at least three domains, preferably more:
- ecommerce inventory
- supply chain routing or simulation
- manufacturing pipeline
- logistics optimization
- traffic flow optimization

I want to make SlotFlow as full-featured as possible while keeping it generic, and have it well documented with various domain examples.
